# 🏆 مشروع: همة حتى القمة (Hemma Hatta AlQimma)

لعبة مسابقات ثقافية عربية كبرى متكاملة مستوحاة من فكرة برنامج "من سيربح المليون". تتميز بتصميم راقٍ وفخم باللونين الأزرق الملكي والذهبي، مع نظام تقدم عبر 10 مستويات تصاعدية الصعوبة، وربط متكامل مع قاعدة بيانات **Firebase Realtime Database**.

---

## 🌟 نظرة عامة ومميزات المشروع

- **عربية بالكامل (100% Arabic & RTL):** واجهة مستخدم، نصوص، أسئلة وخيارات، إشعارات، نتائج، ورسائل تأكيد.
- **10 مستويات تصاعدية الصعوبة:**
  - المستويات 1–3: سهل (Easy).
  - المستويات 4–6: متوسط (Medium).
  - المستويات 7–8: صعب (Hard).
  - المستويات 9–10: قمة التحدي (Very Hard).
- **تصميم تلفزيوني فاخر:**
  - لوحة ألوان ملكية: أزرق كحلي داكن (`#071224`, `#102A56`) وتدرجات ذهبية ميتاليك براقة (`#D4AF37`, `#F5D76E`).
  - خطوط عربية متميزة من Google Fonts: **Cairo** و **Tajawal**.
  - شعار مخصص فخم مصمم بـ SVG يرمز للقمة والنجوم والطموح.
  - شبكة خيارات 2x2 متجاوبة بالكامل.
- **تغذية راجعة مرئية وصوتية حية:**
  - وميض وتوهج أخضر ساطع للإجابة الصحيحة مع كشف دقيق.
  - وميض أحمر للإجابة الخاطئة مع إبراز الإجابة الصحيحة بالأخضر.
  - مؤقت انتظار دقيق (1.5 ثانية) قبل الانتقال للسؤال التالي.
  - قفل الأزرار فور الضغط لمنع التكرار أو التخطي.
- **نظام صوتي إلكتروني مدمج (Web Audio API Synthesizer):**
  - مؤثرات صوتية تفاعلية (نقر، ترقب، نغمة الفوز، جرس الخطأ، ومقطوعة النصر والقمة) دون الحاجة لملفات صوتية خارجية.
  - زر تشغيل وكتم الصوت مع حفظ التفضيل محلياً.
- **بنك أسئلة شامل يدعم أكثر من 1000 سؤال موزعة على 20 تصنيفاً:**
  1. معلومات عامة
  2. تاريخ
  3. جغرافيا
  4. علوم
  5. تكنولوجيا
  6. رياضيات
  7. رياضة
  8. كرة قدم
  9. أدب
  10. اللغة العربية
  11. ثقافة إسلامية
  12. فلك وفضاء
  13. عالم الحيوان
  14. دول وعواصم
  15. اختراعات واكتشافات
  16. جسم الإنسان
  17. شخصيات مشهورة
  18. فنون وثقافة
  19. طبيعة وبيئة
  20. حقائق حول العالم
- **تكامل سحابي كامل مع Firebase Realtime Database:**
  - قراءة الأسئلة وحفظ سجل الجولات (`gameHistory`).
  - تحديث الإحصائيات التراكمية عبر المعاملات الذرية (`transactions`).
  - أداة رفع بضغطة زر واحدة (1-Click Question Seeder) لحقن بنك الأسئلة بالكامل في Firebase.

## 🚀 دليل تشغيل اللعبة وربط Firebase

### 1. تشغيل اللعبة محلياً (Quick Run)
يمكن تشغيل اللعبة مباشرة دون أي بيئة معقدة:
- **الخيار الأول (مباشر):** افتح ملف `index.html` في أي متصفح حديث (Chrome, Edge, Firefox, Safari).
- **الخيار الثاني (موصى به عبر خادم محلي):**
  - باستخدام إضافة **Live Server** في VS Code.
  - أو عبر سطر الأوامر (PowerShell / Terminal):
    ```powershell
    python -m http.server 8000
    ```
    ثم افتح: `http://localhost:8000`

> **ملاحظة:** اللعبة مجهزة بنظام ذكي للعمل بالوضع المحلي مع البنك المرجعي تلقائياً في حال لم يتم ضبط مفاتيح Firebase بعد، ولن تتوقف أو تنهار أبداً.

---

### 2. خطوات ربط Firebase Realtime Database الخاصة بك

#### الخطوة الأولى: إنشاء مشروع في Firebase Console
1. توجه إلى [Firebase Console](https://console.firebase.google.com/).
2. اضغط على **Add Project** (إضافة مشروع) وسمّه مثلاً: `hemma-hatta-alqimma`.
3. اضغط **Continue** حتى يكتمل إنشاء المشروع.

#### الخطوة الثانية: إنشاء Realtime Database
1. من القائمة الجانبية في Firebase Console، اختر **Build** ثم **Realtime Database**.
2. اضغط على **Create Database**.
3. اختر موقع الخادم (Location) واضغط **Next**.
4. اختر **Start in test mode** ثم اضغط **Enable**.

#### الخطوة الثالثة: تطبيق قواعد الأمان (Security Rules)
انتقل إلى تبويب **Rules** في صفحة Realtime Database، وانسخ محتوى ملف `database.rules.json`:

```json
{
  "rules": {
    "questions": {
      ".read": true,
      ".write": true,
      ".indexOn": ["difficulty", "category"]
    },
    "gameSettings": {
      ".read": true,
      ".write": true
    },
    "gameHistory": {
      ".read": true,
      ".write": true
    },
    "statistics": {
      ".read": true,
      ".write": true
    }
  }
}
```
ثم اضغط **Publish**.

#### الخطوة الرابعة: نسخ مفاتيح التكوين إلى المشروع
1. من القائمة الجانبية، اضغط على أيقونة الإعدادات (⚙️) بجوار **Project Overview** واختر **Project settings**.
2. في تبويب **General**، انزل إلى قسم **Your apps** واضغط على أيقونة الويب (`</>`).
3. سجّل التطبيق باسم "Hemma Web".
4. انسخ كائن `firebaseConfig` الناتج.
5. افتح الملف:
   ```
   js/firebase-config.js
   ```
6. استبدل القيم المؤقتة ببياناتك الحقيقية:
   ```javascript
   const firebaseConfig = {
     apiKey: "AIzaSy...",
     authDomain: "hemma-hatta-alqimma.firebaseapp.com",
     databaseURL: "https://hemma-hatta-alqimma-default-rtdb.firebaseio.com",
     projectId: "hemma-hatta-alqimma",
     storageBucket: "hemma-hatta-alqimma.appspot.com",
     messagingSenderId: "123456789",
     appId: "1:123456789:web:abcdef"
   };
   ```

#### الخطوة الخامسة: رفع بنك الأسئلة بنقرة واحدة (1-Click Question Seeder)
1. افتح اللعبة في المتصفح.
2. ستلاحظ في الشريط العلوي أن شارة قاعدة البيانات تحولت للأخضر: `متصل بـ Firebase`.
3. اضغط على أيقونة قاعدة البيانات (🛢️) في الزاوية العلوية لفتح نافذة **إدارة قاعدة البيانات**.
4. اضغط على زر **"رفع الأسئلة إلى Firebase الآن"**.
5. سيقوم النظام بحقن أكثر من 1000 سؤال مدقق بجميع التصنيفات الـ 20 ومستويات الصعوبة مع شريط تقدم مباشر.

## 🎮 نظام وقواعد اللعبة (Game Mechanics)

1. **المستويات العشرة:**
   - كل لعبة تختار 10 أسئلة فريدة تماماً لا تتكرر في نفس الجولة.
   - يتدرج التحدي من السؤال الأول حتى سؤال القمة العاشر.
2. **الخيارات:**
   - 4 خيارات (أ، ب، ج، د) مبعثرة عشوائياً لكل سؤال.
3. **التغذية الراجعة:**
   - إجابة صحيحة: وميض أخضر ساطع + نغمة بهيجة + رسالة تشجيع + انتظار 1.5 ثانية ثم الانتقال للمستوى التالي.
   - إجابة خاطئة: وميض أحمر + كشف الإجابة الصحيحة بالأخضر + جرس تنبيه + انتقال لشاشة النتائج.
4. **شاشة النتائج:**
   - إذا أكمل اللاعب المستوى 10: تظهر شاشة النصر الكبرى مع كأس القمة الذهبي وعبارة:
     > **"مبروك! وصلت إلى القمة!"**
   - في حال الخروج المبكر: تظهر إحصائيات المستوى المنجز وعدد الإجابات الصحيحة والخاطئة ومجموع النقاط، مع إمكانية إعادة اللعب فوراً.
5. **حفظ البيانات السحابية:**
   - تسجل كل جلسة تلقائياً في `/gameHistory`.
   - يتم تحديث إجمالي الألعاب والإجابات الصحيحة في `/statistics`.
